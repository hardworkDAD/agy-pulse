# 07: 本地回环网页看板核心服务、多维筛选、任务树拆解与数据导出

**What to build:** 打通 `dashboard` 子命令启动本地回环服务并在浏览器呈现完整**网页看板**分析界面的端到端能力。用户打开**网页看板**后，可按时间范围、统计粒度、来源（全部/命令行/编辑器）、工作区与模型自由筛选用量与消费趋势图，在会话列表中查看按**任务树**归拢的总账并展开查看任意子代理**单窗对话**的独立消费与速率明细，还可将筛选结果一键导出为 CSV 或 JSON 文件。

**Blocked by:** 05: 统一 SQLite 账本、双源历史重扫与今日/近七日花费及终端统计报表

**Status:** resolved

- [x] 服务端强制仅绑定本地回环地址 `127.0.0.1`（默认端口 `3789`，被占用时自动回退随机可用端口），严格校验请求主机头与来源白名单（拒绝非本地回环跨站请求并返回 `403`），并下发安全响应头。
- [x] 编译期静态内嵌零外部依赖的单页前端资源（无外部 CDN、无外网请求），完整支持中英文界面切换与深浅主题切换。
- [x] 实现概览查询与手动同步接口，支持按时间区间（今日、24小时、7天、30天、本月、全部、自定义起止日期）、时间粒度（自动、小时、天、周）、数据来源（全部、命令行、编辑器）、工作区、模型及是否包含子代理进行多维聚合查询。
- [x] 会话明细列表按**任务树**根节点聚合总字数与总花费（金额与**状态栏**统一计费口径完全一致），支持展开查看其下每个子代理**单窗对话**的模型、字数、速率与花费拆分，并支持关键词搜索与列排序。
- [x] 实现按时间序列、模型汇总、会话明细三种维度的 CSV 与 JSON 文件下载导出接口。
- [x] 进程级本地回环 HTTP 集成测试覆盖全部接口路由、多维筛选结果准确性、**任务树**父子拆解结构、CSV/JSON 导出格式以及非法主机头/来源头的 `403` 拦截验证。
