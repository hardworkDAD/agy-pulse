# 08: 网页看板长效在线保活、独立小窗启动与桌面快捷图标

**What to build:** 补齐**网页看板**完整的桌面应用级体验与无感后台生命周期管理。用户启动看板时优先复用已在线实例并以无地址栏浏览器独立小窗打开，可按需在系统桌面或应用菜单一键安装/移除快捷启动图标；只要用户的看板页面尚未关闭（即便长期最小化或切在后台标签页），后台服务始终保持在线不断连，仅当用户真正关闭全部看板页面后后台进程才在宽限期结束后自动退出回收资源。

**Blocked by:** 07: 本地回环网页看板核心服务、多维筛选、任务树拆解与数据导出

**Status:** ready-for-agent

- [ ] 支持后台守护启动、`open`、`status`、`stop` 等子动作：已有健康运行实例时直接复用该实例地址打开窗口，不重复拉起多个后台进程；执行 `stop` 时优雅停止运行中实例并清理实例发现记录。
- [ ] 重构前后端协同保活与退出机制：移除旧版在页面隐藏或最小化时停发心跳的限制，改为基于活跃页面连接/全状态保活心跳与页面关闭通知维护在线状态——只要任一页面未关闭（含最小化与后台标签页）服务永不超时自杀；当全部页面关闭且宽限窗口内无活跃连接时，后台进程自动退出并清理状态。
- [ ] 支持探测系统已安装主流浏览器以无地址栏独立小窗模式启动**网页看板**，缺失时自动回退系统默认浏览器打开。
- [ ] 支持在三大桌面平台按需创建带有专属指纹标识的应用启动器或桌面快捷图标，并支持按指纹安全移除快捷图标而不误删用户其他文件。
- [ ] 集成测试覆盖单实例复用、`status`/`stop` 生命周期、模拟页面后台静置不掉线与模拟页面彻底关闭后自动退出回收的完整状态流转。
