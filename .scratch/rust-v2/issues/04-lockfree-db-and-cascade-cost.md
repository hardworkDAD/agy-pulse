# 04: 无锁宿主数据库摄取、统一计费口径与任务树实时汇总花费

**What to build:** 打通无锁只读摄取宿主对话数据库并结合统一计费规则在**状态栏**呈现精准指标的完整链路。程序在不向宿主数据库目录产生任何写操作或共享内存锁干扰的前提下，读取服务端真实**上下文压缩**上限来校准进度条水位、统计近期模型流式均速，并按全局唯一的计费公式计算并展示包含主对话与全部后代子代理**单窗对话**在内的整棵**任务树**实时汇总花费（保持**状态栏**版面极简，不罗列子代理清单）。

**Blocked by:** 03: 对话日志增量追踪、上下文压缩感知与工作区元数据显示

**Status:** resolved

- [x] 访问宿主对话数据库时严格执行防锁冲突保护：若存在活跃预写日志则连同伴生文件复制到系统临时目录后只读打开并及时清理，若为静态归档库则以不可变只读模式打开，确保宿主原目录零写入、零锁竞争。
- [x] 解码对话数据库中的压缩配置与生成元数据，提取服务端实际**上下文压缩**上限并与模型声明上限取较小值来校准**状态栏**上下文水位百分比。
- [x] 汇总最近非空对话数据库的流式生成数据，计算各模型的加权流式输出均速与平均首字延迟供**状态栏**展示。
- [x] 落地全局唯一的字数归一化与计费公式：统一纳入系统提示词字数、按模型家族明确区分原始输入字数是否已包含缓存读写字数、支持长上下文阶梯费率，并对特定路由模型按开关决定是否采信原生上报费用。
- [x] 解析主对话与子代理之间的父子血缘关系并结合对话日志尾部未落库增量，使**状态栏**显示的汇总金额完整覆盖整棵**任务树**的真实消费。
- [x] 黑盒测试使用真实对话数据库样本（含活跃预写日志场景与多级子代理**任务树**场景）验证零原目录副作用、压缩上限校准及**任务树**汇总金额精度。
