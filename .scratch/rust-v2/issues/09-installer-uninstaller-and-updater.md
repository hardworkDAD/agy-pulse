# 09: 宿主状态栏安装器、安全卸载器与 GitHub 版本检查及手动自更新

**What to build:** 打通软件安装注册、日常版本更新提示、手动安全自更新与干净卸载的全生命周期运维能力。用户可一键将原生二进制注册到宿主**状态栏**设置并部署至用户独立命令目录（不污染反重力自有程序目录）；日常使用时每 24 小时低频检查一次 GitHub 新版本并在**状态栏**给出安静提示；手动执行 `update` 时自动下载匹配当前系统与芯片架构的预编译包、完成 SHA-256 校验并原子替换自身；执行卸载时干净移除配置与自身产物且默认保留珍贵的历史**账本**。

**Blocked by:** 01: 最小可运行状态栏主干贯通与黑盒测试基座

**Status:** ready-for-agent

- [ ] 实现安装与注册能力：保留宿主设置文件中已有的其他全部字段，安全写入或更新**状态栏**命令指向原生二进制（若遇损坏设置文件先自动备份再修复），并将命令行入口部署至用户独立可执行目录，严禁向反重力官方程序安装目录写入任何文件。
- [ ] 实现低频后台版本检查：按 24 小时周期异步查询可配置的 GitHub 发布版本信息并更新本地版本状态记录，存在新版本时在**状态栏**渲染温和的升级提示，绝不自动静默替换程序。
- [ ] 实现手动 `update` 自更新：下载当前操作系统与架构对应的发布压缩包及校验清单，强制通过 SHA-256 完整性校验与防降级协议检查后执行原子替换（含 Windows 运行中可执行文件的重命名热替换）；校验失败时拒绝覆盖并给出明确报错。
- [ ] 实现安全卸载能力（含子命令与卸载脚本调用）：移除宿主设置中的本工具**状态栏**配置、清理缓存/临时目录、移除命令行入口与匹配专属指纹的快捷图标；默认完整保留历史**账本**与用户配置备份，仅在显式传入彻底清除参数时才删除**账本**。
- [ ] 在隔离临时目录与本地临时回环发布源服务（零 Mock）下，端到端测试覆盖安装注册、损坏设置备份恢复、版本检查提示、压缩包 SHA-256 校验成功/篡改拦截自更新，以及默认保留**账本**与显式清除**账本**的卸载流程。
