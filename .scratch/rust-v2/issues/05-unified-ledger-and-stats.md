# 05: 统一 SQLite 账本、双源历史重扫与今日/近七日花费及终端统计报表

**What to build:** 建立基于内嵌静态 SQLite（WAL 模式）的统一长期**账本**，打通自动扫描命令行端与编辑器端原始对话记录入库、在**状态栏**展示今日累计与滚动近七日花费，以及通过 `stats` 子命令直接在终端查看多时间维度消费报表的完整闭环。老用户升级或新用户首次安装后无需任何旧账本迁移文件，即可通过自动扫描本地既有对话记录立即获得完整的历史与当日消费统计。

**Blocked by:** 04: 无锁宿主数据库摄取、统一计费口径与任务树实时汇总花费

**Status:** resolved

- [x] 使用内嵌静态编译 SQLite（开启 WAL 模式、忙等待超时与仅本人读写文件权限）创建并维护统一**账本**，彻底替代原独立的每日花费文件与文本降级账本。
- [x] 自动扫描并增量归档命令行端与编辑器端数据目录下的全部对话数据库，记录数据来源标识并避免重复导入未变更记录；**状态栏**主路径按节流间隔轻量同步当前活跃对话。
- [x] 在**状态栏**准确展示今日累计花费与滚动近七日累计花费；当某场对话因重置或**上下文压缩**出现单会话累计值回退时，推进游标而不倒扣已计入的当日或当周花费。
- [x] 实现 `stats` 子命令（及兼容参数旗标），支持按时间区间与来源筛选并在终端清晰打印模型分布、字数明细、生成均速与总花费报表（支持中英双语）。
- [x] 隔离临时目录黑盒测试覆盖命令行与编辑器双源混合重扫、跨天/跨周滚动累计、压缩回退防倒扣、并发读写下无锁死以及 `stats` 终端输出校验。
