# 06: 交互式终端配置向导（实时状态栏预览与原子保存）

**What to build:** 打通 `config` 子命令的交互式终端设置向导体验。用户在终端启动向导后，可通过方向键、快捷键或数字键自由切换主题配色、界面语言、**模型配额**面板样式、上下文告警阈值及各项显示元素开关，并在向导界面内即时看到真实渲染引擎生成的**状态栏**动态预览；确认保存后配置以原子方式安全落盘，取消退出则不改动原有配置。

**Blocked by:** 02: 标准输入模型配额展示（表格与紧凑模式）, 03: 对话日志增量追踪、上下文压缩感知与工作区元数据显示

**Status:** resolved

- [x] 支持通过 `config` 子命令及兼容旗标启动交互式终端向导；在非交互式终端环境下给出清晰提示并安全退出。
- [x] 支持键盘上下移动、空格/回车切换开关与枚举项、视口自动滚动，覆盖主题预设、语言、配额展示样式（仅含有效本地样式，不含已移除的云端配额项）、水位阈值与各状态元素开关。
- [x] 每次调整选项后在向导界面内即时重绘真实的**状态栏**多行预览效果（含配色与当前语言文案）。
- [x] 按保存键时采用“写入同目录临时文件 → 刷盘 → 原子重命名”方式更新全局配置文件，保留用户其他未改动自定义键值；按退出键或中断信号时恢复终端原始状态且不污染原配置文件。
- [x] 测试覆盖配置原子写入完整性、旧版配置文件读写往返保持及非交互式标准输入下的安全回退行为。
