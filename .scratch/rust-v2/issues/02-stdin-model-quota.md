# 02: 标准输入模型配额展示（表格与紧凑模式）

**What to build:** 打通从宿主标准输入解析厂商级**模型配额**窗口数据到**状态栏**多模式展示的完整功能。用户无需任何额外认证或外部联网，即可根据配置在**状态栏**看到各模型厂商 5 小时窗口与周窗口的剩余额度百分比、可视化进度条与预计重置倒计时，并可在表格模式、紧凑单行模式与隐藏配额模式之间自由切换。

**Blocked by:** 01: 最小可运行状态栏主干贯通与黑盒测试基座

**Status:** resolved

- [x] 解析宿主标准输入中的厂商级**模型配额**字段（含 Google、Claude 及兼容厂商的 5 小时窗口与周窗口剩余比例及重置时间），自动识别更具约束力的临界窗口。
- [x] 在“表格模式”下完整渲染多厂商 5 小时与周窗口进度条、百分比、阈值告警变色及重置倒计时（支持中英双语与 ASCII 降级）。
- [x] 在“紧凑模式”下渲染单行厂商级剩余配额汇总摘要；在“隐藏模式”下不输出任何配额行。
- [x] 当旧版用户配置中残留已退役的单模型私有云端配额样式枚举值时，自动平滑回退按“表格模式”渲染而不报错。
- [x] 全程零外部网络请求、零本地登录凭据或系统密码箱访问；进程级黑盒测试覆盖多厂商窗口组合、临界告警变色、过期重置时间处理与三种展示样式切换。
