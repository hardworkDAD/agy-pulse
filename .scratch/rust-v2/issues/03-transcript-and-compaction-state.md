# 03: 对话日志增量追踪、上下文压缩感知与工作区元数据显示

**What to build:** 打通增量读取宿主对话事件日志与工作区配置信息并实时呈现在**状态栏**的端到端能力。用户在多轮长对话与多智能体协作中，可在**状态栏**实时看到本轮提示词缓存命中率、瞬时输出生成速率、近期活跃子代理模型的生成速率摘要，以及当前工作区识别到的规则文档数与工具服务数；当对话发生**上下文压缩**时，活跃上下文计数自动归零重算并保留历史峰值水位提示。

**Blocked by:** 01: 最小可运行状态栏主干贯通与黑盒测试基座

**Status:** resolved

- [x] 基于文件唯一标识与头部哈希校验实现对话事件日志的字节偏移增量扫描，在日志被轮转或重写时自动失效重建偏移，且支持按需回查完整日志处理截断字段。
- [x] 准确计算并在**状态栏**展示当前轮次的缓存命中率百分比与瞬时输出生成速率（过滤过短时间窗口毛刺与异常极值）。
- [x] 识别对话内派发的子代理与蜂群成员模型活动，在**状态栏**紧凑展示最多三个近期活跃子代理模型的速率摘要，并在超过闲置轮次或时间阈值后自动隐去。
- [x] 识别对话日志中的**上下文压缩**检查点事件：触发后正确重置当前活跃上下文与本轮缓存基线，同时记录并展示压缩前达到的历史峰值水位。
- [x] 纯离线扫描当前工作区与用户配置中的智能体规则文档数量及已配置工具服务数量，并在**状态栏**准确呈现。
- [x] 隔离临时目录黑盒测试覆盖多轮增量追加扫描、日志截断回查、**上下文压缩**前后水位跳变与峰值保留、子代理速率展示与过期隐去、以及工作区规则与工具计数。
