# 01: 最小可运行状态栏主干贯通与黑盒测试基座

**What to build:** 编译产出可独立运行的原生二进制（同时支持全称与简写命令入口），打通从读取用户配置与宿主标准输入到终端输出多行**状态栏**的第一条完整端到端链路。当宿主传入包含模型信息、推理强度、套餐标识、当前目录、基础上下文水位与原生费用的标准输入时，二进制在严格超时保护下输出带主题配色、中英双语适配、Unicode/ASCII 自动降级、本地版本分支名与窄屏安全截断的**状态栏**文本；遇到空输入、格式残缺或局部错误时优雅降级、记录错误日志并始终以退出码 `0` 结束。同时建立基于环境变量隔离临时目录的进程级黑盒测试夹具。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 编译生成单一原生可执行文件，支持帮助与版本查询参数，并在无子命令时进入宿主标准输入渲染模式。
- [ ] 支持按“内置默认 → 全局配置 → 工作区配置 → 环境变量”优先级合并配置；直接读取旧版用户配置文件时不报错，对已退役的旧字段静默忽略；当总开关关闭时立即静默退出且退出码为 `0`。
- [ ] 正确渲染**状态栏**首行与上下文水位基础行（模型简称、推理强度、套餐徽章、工作目录名、本地版本库当前分支名、原生花费及上下文百分比进度条）。
- [ ] 自动识别系统语言（中文/英文）与终端字符集支持（Unicode 图标与纯 ASCII 降级），并支持通过配置或环境变量强制指定。
- [ ] 在窄终端列宽下按优先级逐级精简次要字段，确保东亚宽字符、表情符号与颜色转义序列截断后无错位折行或乱码残片。
- [ ] 全程受 1500 毫秒硬超时保护，全库无未捕获恐慌；喂入空标准输入或非法文本时仍以退出码 `0` 正常结束并仅在权限受限的日志中记录诊断信息。
- [ ] 进程级隔离临时目录黑盒测试覆盖正常渲染、窄屏降级、ASCII 降级、旧版配置兼容及空/异常输入兜底场景。
