## [1.0.0] - 2026-11-18

### Added
- **Unified `agy-pulse` Single-Process Architecture**: Merged the legacy HUD and `agy-statusline` into a single zero-dependency Node.js runtime (`runtime/bin/agy-pulse.js`), eliminating Python + Bash + `mktemp` subprocess glue.
- **`runtime/brand.js`**: Centralized branding (`agy-pulse`, `1.0.0`), config filename (`agy-pulse.config.json`), and safe `resolveRepoSlug` without hardcoding an upstream repository.
- **`runtime/compaction.js`**: Pure-JS Protobuf wire decoder (with `BigInt` varint shifting) and SQLite read-only `CheckpointConfig.max_context_tokens` extractor (`gen_metadata` `f1.f9.f10.f4` & `executor_metadata` `f10.f2.f5`), with `size:mtimeMs` WAL-safe caching and cold-start recent-DB fallback; plus 30-DB sliding-window `gen_metadata` performance decoder (`resolveModelPerfStats` / `querySqliteModelPerf`) computing per-model pure streaming weighted average speed (`∑outputTokens / ∑streamingDuration`) and arithmetic average TTFT (`f1.f11` / `f1.f12`) with incremental `_db_perf` signature caching.
- **Line 1 Streaming Avg Speed & TTFT (`speed.js`, `parser.js`, `renderer.js`, `renderer/lang.js`, `config-wizard.js`)**: Integrated `state.modelPerf` and `formatTtft` into Line 1 main-model and active `/swarm`/subagent speed badges (`输出: X.X tok/s (首字 Y.Ys)` / `out: X.X tok/s (ttft Y.Ys)`), including cold-start display on new sessions and lossless fallback when `modelPerf` is empty.
- **`runtime/renderer/context-monitor.js`**: Native 5-level smooth context & compaction progress bar (`█▓▒░·` / `#=-.`), compaction counter & historical peak (`Compacted×N(peak X)` / `压缩×N(峰X)`), cache hit rate, output tokens, cost, and `>=85%` imminent compaction alert in both `zh` and `en`.
- **2026 Model Coverage**: Full support for `gemini-4-carbon-*`, `gemini-4-hydrogen-*` (`XHigh`), `gemini-4-argon-*`, `gemini-3.8-flash-*`, `gemini-pro-orchestrator(-argon)`, `claude-opus-4-6-thinking`, `claude-sonnet-4-6`, and `gpt-oss-120b-medium` across quota discovery, pricing, abbreviations, and collision-free compact names.
- **Per-Model Rolling Swarm & Subagent Speeds (Two-Layer Persistence)**: `parser.js` (`TRANSCRIPT_CACHE_VERSION = 5`) retains all registered `/swarm` workers and `invoke_subagent` child sessions across `killed`, `SYSTEM_MESSAGE` stop, `USER_INPUT` turns, and idle gaps, persisting observed speeds in `transcript-cache` and `_persisted_child_speeds` (`agy-pulse-compaction-cache.json`) even after child logs are cleaned up; `compaction.js` records `lastUpdatedMs` per model in `resolveModelPerfStats`, and `renderer.js` merges `childModelSpeeds` with non-main `modelPerf` entries (up to `MAX_CHILD_MODELS_DISPLAY = 3`) so Line 1 continues displaying multi-model speeds and TTFT even in fresh empty sessions.
- **Comprehensive Unit Tests**: Added `compaction.test.mjs`, `renderer.context-monitor.test.mjs`, `update-checker.test.mjs`, and `config-wizard.test.mjs`, plus expanded regression suites.

### Fixed
- **Cache-Inclusive Double-Counting & Empty `current_usage` Fallback**: Normalized `promptCtx` and `turnHistoryMaxByMode` (`inclusivePeak` / `exclusivePeak`) and fell back to `state.lastTurnUsage` when `current_usage` is `{}` or all zeros.
- **Incremental Transcript Scanning & Timing**: Added byte-offset incremental caching in `parser.js`, fixed `PLANNER_RESPONSE` duration closing on `SYSTEM_MESSAGE` / `USER_INPUT`, prevented 429 false positives via structured error inspection + `transcript_full.jsonl` lookup, and returned `null` branch in non-Git directories.
- **Speed Calculation Edge Cases**: Fixed first-turn plain-text reply `null` speed, relaxed token alignment tolerance, guarded non-first-turn open/interrupted turns (`MAX_OPEN_TURN_TRAILING_MS` & `interrupted: true`) against `now - startMs` decay, and tracked `turnBaselineOutput` so cumulative-only `total_output_tokens` recalculates accurately across `<500ms` pending and open-to-closed transitions.
- **Auth & Quota Cache Stability**: Prevented Linux keyring hot-path blocking on `fast: true`, prevented stale token mirror shadowing on account switch, prevented failed background refreshes from overwriting valid quota cache with `[]`, and used `base64url` for JWT decoding.
- **Cost & Ledger Accuracy**: Fixed first-turn baseline omission, context-compaction monotonic cursor regression, concurrent multi-session writes, and offline 7-day rolling weekly cost fallback in `daily-cost.js`; aligned `cost.js` `MODEL_PRICING` with `antigravity-context-viewer` rates (Claude 5.5, Gemini 4 Carbon/Hydrogen/Argon, Gemini 3.x Flash, and `>200k` tiered Gemini Pro pricing), guarded `cacheInclusive` subtraction against mutually exclusive `input < cacheTotal` clamping, ignored `<= 0` native cost placeholders, added per-turn model-aware cost accumulation (`totalInputTokens`, `TRANSCRIPT_CACHE_VERSION = 4`) in `parser.js` and SQLite session-tree per-model cost aggregation (`_db_perf` `schemaVer: 2`, capacity `64`) in `compaction.js`, and unified single `totalCostUsd` rendering across Line 1, `context-monitor.js`, and `daily-cost.js`.
- **Renderer, Config, Installer, & Updater**: Passed `targetCwd` to `loadConfig()`, deep-merged `FULL_DEFAULT_CONFIG`, honored `config.enabled === false`, omitted hardcoded `display.unicode` to enable auto-detection, rendered `--` for missing quota windows instead of fake `100%`, preserved `enabled` / `stack_with_default` and backed up corrupt JSON in `settings.json`, preserved saved global config across `bootstrap.js` upgrades, honored `AGY_PULSE_DATA_DIR`, added SemVer 2.0 prerelease comparison + redirect support + `cwd` config lookup in `update-checker.js`, migrated skill directory to `skills/pulse-config/SKILL.md`, added `LICENSE`, and expanded `config-wizard.js` and `uninstall.js`.
