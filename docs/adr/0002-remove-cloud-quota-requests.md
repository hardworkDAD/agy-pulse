# 移除向反重力/Google 服务端主动发请求的云端配额模块

旧版“云端配额”功能会在宿主外部提取本地 OAuth 登录令牌并伪装客户端请求头直接调用 `daily-cloudcode-pa.googleapis.com` 等私有接口，存在违反服务条款（ToS）触发账号风控封禁的风险。我们决定在 `v2.0.0` 彻底移除云端配额请求、配套 Token 提取逻辑及 `diagnose` 云端鉴权诊断功能，配额展示完全消费宿主通过标准输入合法传入的数据（保留配额表格与紧凑汇总，退役仅云端私有接口可支撑的逐模型细分配额模式）；与反重力服务端无关的 GitHub 版本更新检查及本地功能正常保留。
