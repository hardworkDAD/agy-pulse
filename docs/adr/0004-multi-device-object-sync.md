# 采用按设备单写对象协议与单账本分列隔离实现多机同步

为支持同一用户的多台设备按**账号 → 设备 → 来源端 → 任务树**层级汇总跨机消费统计并共享最新**配额快照**，同时兼顾 WebDAV、S3 兼容存储、Cloudflare Worker 与本地同步目录 4 种**同步远端**且杜绝多机并发写冲突，我们决定放弃直接同步整库 SQLite 文件、高频碎事件文件及为 Cloudflare Worker 单独维护 D1 SQL 协议的方案，统一抽象为**按设备单写、按账号读合并**的对象存储契约：每台**设备**仅写入各自路径下的 `manifest.json`（含设备元信息与最新**配额快照**）和按自然月打包的 `YYYY-MM.jsonl.gz` 账本分片（历史月份凭校验和跳过重复传输，且载荷严格不含对话正文与本机目录/Git 分支信息）。在本地持久化上，延续 ADR-0003 的单 SQLite **账本**架构而非拆分双库 `ATTACH + UNION ALL`，通过在核心表新增 `account_id`、`device_id` 列实现隔离：**状态栏**热路径严格仅查本机 `device_id` 并在后台节流静默 Push（零阻塞、不混合远端数据），**网页看板**默认聚合全局并采用“先秒开缓存、后异步 Pull 刷新”策略；同步遵循只增/更新不传播删除语义（报废设备仅由显式命令清理），**单窗对话**入账即锁定**账号**归属不随同机切号回写，且所有同步配置与密钥强制仅存用户全局 `0600` 私有文件以防止误提交至工作区 Git 仓库。
