# 采用单一原生 Rust 二进制重构本地运行时（v2.0.0）

宿主每次模型步骤结束后都会以短命子进程方式调用状态栏命令，现行 Node.js 运行时存在百毫秒级冷启动开销及对本机 `Node.js >= 22.5`、系统 SQLite/PowerShell 等外部环境的脆弱依赖。我们决定在 `v2.0.0` 将全部本地运行时、CLI 子命令、SQLite 账本与本地看板服务端收敛为单一静态原生 Rust 二进制（通过 GitHub Releases 预编译 5 大主流平台二进制配合一键脚本分发，停止维护 npm 包），仅保留宿主协议要求的静态插件声明文件并将零依赖看板前端 HTML/CSS/JS 直接内嵌进二进制。升级时不编写旧版账本文件兼容迁移逻辑，仅继承用户个性化配置文件，历史账单直接通过重新扫描宿主原始对话记录并按统一修正后的计费口径自动重建。
