# 在本机网页看板内置零登录双配置管理与只写凭据契约

为降低调整**偏好配置**与初始化**同步配置**的终端门槛，同时延续 ADR-0001 的单二进制零外部依赖形态与 ADR-0004 的凭据隐私底线，我们决定直接在现有本机**网页看板**内通过顶栏抽屉/弹窗承载配置管理（与现有 CLI/TUI 共享同一底层配置文件作为唯一真相源，不拆独立管理后台，也不引入**账本**数据运维或安装升级操作）。安全与持久化契约明确如下：服务端保持严格 `127.0.0.1` 监听与免登录体验，但所有配置写/测/预览接口强制校验随页面注入的进程级随机 CSRF Token 头及严格同源头；**同步配置**采用凭据只写不回显语义（读取仅返回已配置与环境变量覆盖状态，留空保存保留磁盘原值，环境变量凭据严禁反写落盘）；**偏好配置**在网页端仅读写全局文件而不触碰业务工作区目录（防污染项目 Git 仓库），并通过未知字段深合并、同进程写锁及文件哈希乐观并发校验（冲突返回 `409`）防范与终端入口并发覆写；实时**状态栏**预览由后端直接复用 Rust 渲染引擎输出，杜绝前后端双份渲染逻辑漂移。
